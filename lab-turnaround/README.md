# Lab Test Turnaround Analysis

## Objective
Analyze lab test processing times to identify bottlenecks and improve efficiency.

## Dataset
- Source: Public lab datasets / simulated NHS lab data  
- Contents: Test type, processing time, patient demographics, lab technician info

## Tools & Methods
- Python: Pandas, NumPy
- Visualization: Matplotlib, Seaborn
- Statistical Analysis: Hypothesis testing, correlation analysis

## Steps
1. Data cleaning and formatting
2. Exploratory Data Analysis (EDA)
3. Identify delays and bottlenecks
4. Visualize performance metrics
5. Recommend process improvements

## Impact
- Improves lab efficiency
- Reduces patient waiting times

## Files
- `notebooks/` : Jupyter notebooks for analysis
- `data/` : Sample datasets or scripts to load data
- `reports/` : PDF or images of dashboards/visualizations
