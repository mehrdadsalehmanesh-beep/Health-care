# Patient Readmission Prediction

## Objective
Predict which patients are at high risk of hospital readmission using historical patient and lab data.

## Dataset
- Source: [NHS Open Data / Kaggle simulated dataset]  
- Contents: Patient demographics, hospital admissions, lab results, diagnosis codes

## Tools & Methods
- Python: Pandas, NumPy
- Visualization: Matplotlib, Seaborn, Plotly
- Machine Learning: scikit-learn (Logistic Regression, Random Forest)

## Steps
1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. Model building and evaluation
5. Visualization of results

## Impact
- Helps hospitals identify high-risk patients early
- Optimizes resource allocation and care planning

## Files
- `notebooks/` : Jupyter notebooks for analysis
- `data/` : Sample datasets or scripts to load data
- `reports/` : PDF or images of dashboards/visualizations
